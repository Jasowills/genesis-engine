**Research date:** 2026-11-27. **Scope:** primary sources (official docs/project sites, GitHub repos and LICENSE files, release notes/changelogs, standards docs, authors' papers). OSM Wiki is treated as the community-authored specification for OSM tagging, not as independent proof of global data completeness.

**Evidence discipline:** every claim below is tied to a cited URL. `UNVERIFIED` marks claims that could not be confirmed from a primary source; `CONFLICT` marks contradictory primary/community statements. These are findings only — no final architecture decision is made here.

All URLs were accessed **2026-11-27**.

## 4. Cross-cutting observations (evidence only)

1. **Determinism:** the Rand book explicitly warns that seeding does not imply reproducibility; use a named fixed algorithm (e.g. ChaCha8/12), pin dependency versions, and test golden vectors. `StdRng`/`SmallRng` are declared non-portable and may change values in any release ([seeding](https://rust-random.github.io/book/guide-seeding.html), [reproducibility](https://rust-random.github.io/book/crate-reprod.html), accessed 2026-11-27).
2. **Incremental regeneration:** Blender documents Bake Nodes/Simulation Zone baking and warns baked data is not guaranteed cross-version ([baking](https://docs.blender.org/manual/en/latest/modeling/geometry_nodes/baking.html)). osm2streets lists user-edit preservation across OSM updates as *planned* ([README](https://raw.githubusercontent.com/a-b-street/osm2streets/main/README.md)). Houdini Engine offers HDA parameterisation and PDG task graphs ([SideFX](https://www.sidefx.com/products/houdini-engine/)). No primary source retrieved establishes a mature incremental rebuild contract for OSM-derived 3D scenes; this remains a design question.
3. **Provenance:** OSM Wiki states `building=*` describes form, not current use; Microsoft confidence applies to footprint, not height; Google Open Buildings explicitly has no type/height/address; OSM `lanes` may be only a minimum. These are direct source-level reasons to store sourced/inferred distinctions rather than collapse attributes into a single mesh.
4. **Licence conflicts/limits:** OSM2World MIT (LICENSE.txt) vs LGPL (OSM Wiki). CityEngine SDK repo Apache-2.0 but binary SDK and commercial use governed by Esri terms, with redistribution/web-service restrictions. Blender/Blosm GPL; Houdini proprietary with Indie thresholds; Microsoft footprints CDLA Permissive 2.0; Google Open Buildings CC BY-4.0 or ODbL; Microsoft roads ODbL; OSM data ODbL; Mapillary imagery CC BY-SA unless indicated otherwise.
5. **Thin evidence:** global OSM building completeness percentages; exact CityEngine pricing/current OS support; CGA reference documentation (403 to this agent); OSM2World incremental API; license text for WFC/Shapely/GEOS/Rand; Google temporal dataset; Microsoft code release promise status; cross-version determinism of Houdini/CityEngine; and any production-quality facade reconstruction from licensed street imagery. These need follow-up before architecture commitments.
